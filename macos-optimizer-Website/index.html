macos-optimizer

A menu driven macOS optimisation script (script.sh), adapted from Sami Halawa's macOS optimiser: https://github.com/samihalawa/macos-optimizer . On start it prints system information (hostname, macOS version, kernel, CPU, memory, storage), then loops a numbered menu. Each number below is one item of cargo: read what it does before it crosses. The switches argued about, and the rows that run other rows.

  • 6Enable TRIM, asks for confirmation first, needs a restart

Sailing notes

Choosing a menu item applies that change at once; only TRIM asks for confirmation first, and TRIM needs a restart. Option 24, the safe set, runs Spotlight off, App Nap off, automatic termination off, fsck -fy, lid wake on, DNS flush, Spotlight rebuild, and Secure Empty Trash. After each action the script reports success or error and waits for Enter (or q to return to the menu). The script is macOS only and was checked with bash -n; it was not run live, because running it would change a real Mac's system settings. Settings can be returned to their defaults in System Settings or by running the opposite menu choice where one exists.
