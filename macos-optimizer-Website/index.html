macos-optimizer

A menu driven macOS script in script.sh, adapted from an upstream project, with my own changes kept and credited.

What this is

I did not write this script from a blank file, and this page will not pretend I did. script.sh carries a copyright line for Sami Halawa at the top, and my README credits the original project at github.com/samihalawa/macos-optimizer. What sits in my repo is that script, adapted, with a short list of changes that are mine.

The script itself is a numbered menu for a Mac. On start it prints system information, hostname, macOS version, kernel, CPU, memory, and storage, then it loops through 25 choices plus quit. Pick a number and that action runs at once. The ledger below is the honest split of who did what.

My reason for keeping a copy at all is the Gatekeeper change. The original turned Gatekeeper off as an optimization. I removed that line and made the same slot turn Gatekeeper on. That one decision is the reason this repo exists, and I would rather have a small claim that is true than a large one that is not.

After each action the script reports success or error and waits for Enter, or q to return to the menu. TRIM is the one item that asks for confirmation first and expects a restart, which is why it stays out of the safe set.

Honest notes

The script intro says no changes are made without explicit confirmation. That is not true for menu choices. Picking a number applies the change at once, and only TRIM asks first. I left that wording as written and recorded the mismatch in the README instead of rebuilding confirmations for all 25 options.

I checked this script with bash -n only. I did not run it live. It changes real system settings on a Mac, and this work was done on a Linux host, so a live run was out of the question in any case.
